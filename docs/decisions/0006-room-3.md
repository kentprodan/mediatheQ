# 0006. Room 3 for local database

- Status: Accepted
- Date: 2026-10-18 (replaces "Room" in the old stack decision)

## Context

Room 3.0 (`androidx.room3`) is stable (3.0.3 on 2026-10-18). Compared to Room 2.x it is Kotlin- and coroutine-only, requires KSP and a `SQLiteDriver`, drops SupportSQLite APIs, and adds FTS5 support (`@Fts5`, including a trigram tokenizer). A new project has no Room 2 code to migrate.

## Decision

- Use Room 3 (`androidx.room3:room3-runtime`, `room3-compiler` via KSP, Room 3 Gradle plugin with `schemaDirectory`).
- Bundled SQLite driver, so database tests run on the plain JVM.
- Search uses FTS5 with diacritic-insensitive matching ("Mosoi" finds "Moșoi").

## Consequences

- Most Room tutorials online show Room 2 APIs; always check Room 3 release notes and docs.
- Exported schemas are committed to `schemas/` and every schema change has a migration test.
