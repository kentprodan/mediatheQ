# 0022. Open-source licenses generated at build time with AboutLibraries

- Status: Accepted
- Date: 2026-10-26

## Context

mediatheQ is GPL-3.0-or-later (ADR 0001) and ships about 150 third-party libraries. It must list each of them with its
license, generated by the build rather than kept by hand (#70), plus the code and assets copied into the repository
(`THIRD_PARTY.md`) and the app's own license and source.

Considered: AboutLibraries (actively maintained, writes one JSON per variant, can carry full license texts) and Cash
App's Licensee (SPDX ids and URLs only, no texts, last release a year old). Google's oss-licenses plugin needs Play
services at runtime, which the stack excludes.

## Decision

- The AboutLibraries Gradle plugin (`com.mikepenz.aboutlibraries.plugin.android`, 15.3.0) runs in `:app` only, the
  module that sees the shipped classpath. Each variant gets its own report (`R.raw.aboutlibraries`), so the release
  report has no debug-only libraries.
- `offlineMode = true`: the build needs no network (CI does not depend on GitHub or SPDX). Offline the plugin knows only
  license names, so the standard texts of the licenses in use (Apache-2.0, BSD-3-Clause, MIT, from apache.org and
  spdx.org) live in `app/aboutlibraries/licenses/`.
- `strictMode = FAIL` with those three licenses allowed: a library under another license stops the build until its
  text is added and its compatibility with GPL-3.0 is checked.
- No runtime library: `:feature:settings` parses the JSON with kotlinx.serialization; `:app` hands it over through
  `settingsEntry`, like the version name.

## Consequences

- A test in `:app` reads the release report: shipped libraries are there, debug-only tools are not, and every library
  has a license with its full text.
- Copied assets stay hand-listed (no tool can find them): `COPIED_ASSETS` mirrors `THIRD_PARTY.md`, checked by a test.
- A new kind of license in a dependency update fails the build on purpose.
- Plugin updates follow the usual rule: check the release notes, keep offline mode.
